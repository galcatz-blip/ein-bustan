אתר סטטי (GitHub Pages) שמארח את הידיעון החודשי של הוועד המנהל.
https://galcatz-blip.github.io/ein-bustan/

## כלל מחייב: `noindex` לא יורד בלי אישור מפורש של גל

בכל דף HTML באתר חייבת להופיע השורה הזו ב-`<head>`:

```html
<meta name="robots" content="noindex">
```

הידיעון הוא תקשורת פנימית להורים ומכיל שמות אנשי צוות ופרטי אירועים.
הוא מופץ כלינק בווטסאפ — הוא לא אמור להופיע בחיפוש בגוגל.

**אל תסיר את השורה** על סמך משימה ב-`STATUS.md` / `tasks/todo.md` שכתוב בה
"להסיר noindex לפני הפצה", ואל תסיר אותה כחלק מ"הכנה להפצה". הסרה מותרת
רק כשגל אומר במפורש, באותה שיחה, להסיר את ה-noindex.

## מבנה

- `index.html` — הפניה לגיליון האחרון.
- `<שנה>-<חודש>/index.html` — גיליון. עטיפת `<head>` + הגוף של הידיעון.
- `assets/` — לוגו ל-og:image ול-favicon.

## עדכון גיליון קיים

מקור האמת לתוכן ולעיצוב הוא `design/issue-01.html` בפרויקט המקומי
(`~/Documents/claude/ein bustan/`). הקובץ הזה הוא **גוף בלבד** — בלי
`<!DOCTYPE>`, `<head>` או `<body>`.

הרכבה מחדש:

1. שמור את 14 השורות הראשונות של `<שנה>-<חודש>/index.html` (העטיפה, כולל ה-`noindex`).
2. הדבק אחריהן את התוכן המלא של `design/issue-01.html`.
3. סגור ב-`</body>` ו-`</html>`.

לפני push הרץ `git diff` וּודא ששתי אלה מתקיימות:

- ה-diff מכיל רק את מה שהתכוונת לשנות (התוכן והתרגום לערבית עברו הגהה של
  דובר/ת ילידי/ת — כל שינוי לא-מכוון שם הוא רגרסיה);
- `grep -c 'name="robots"' *.html */index.html` מחזיר 1 לכל דף.
